1. Project Overview
This is a grocery e-commerce site with one rule that shapes everything: customers can buy only combo packs. Individual items exist inside the admin panel for building combos and tracking stock, but they never appear in the storefront as sellable products.
1.1 Main actors
Actor
What they can do
Guest
Browse combos, see the overall-discount price, register, log in.
Normal customer
Everything a guest can do, plus cart, checkout, orders, addresses. Gets the overall discount only.
Investor customer
A normal customer whose investment was approved by admin. Gets overall discount + investor discount. Has an investor dashboard.
Staff
Admin panel access limited by permission keys (for example combos.manage, orders.manage).
Admin
Full access: combos, items, discounts, investment plans, approvals, reports, settings.
1.2 Core business rules
Only combos are sellable. A combo is a list of items with quantities. Cost price is calculated from item costs; base (sale) price is set by admin.
Overall discount is created by admin. Scope can be global, category, or a single combo. It can be a percentage or a fixed amount. The most specific scope wins: combo, then category, then global.
Investor discount comes from the investor's plan (Silver, Gold, and so on). Admin can override the percentage per combo or per category inside a plan, or set a custom percentage for one investor.
Investor status is not a user field. It is derived from investor_profiles (status = active), so one user table serves everyone.
Stock is per item. A combo is available only as many times as its scarcest item allows: MIN(FLOOR(stock / quantity)).
Never sell below cost. A setting keeps the total discount from pushing the price under the cost price. A second setting caps the total discount percentage.
1.3 Investment plan model
Assumption to confirm
This plan treats investment as a membership / discount programme, not a profit-sharing investment. Customers pay a plan amount and receive a discount for a fixed duration. If you want real profit sharing or returns, that changes the database and needs legal review under Bangladesh financial regulations before development.
Admin creates plans: name, minimum and maximum amount, discount %, duration, lock-in period, refundable or not.
Customer applies and pays. Admin reviews KYC and approves or rejects.
On approval the investor profile becomes active and the discount applies automatically in the storefront.
When the plan expires, or the investor is suspended, the investor discount stops. The overall discount still applies.
2. Discount and Pricing Rules
The final price is calculated in one place only: pricing.service.ts, which uses the pure function calculatePrice() in utils/pricing.util.ts. The storefront, cart and checkout all call the same code, so prices never disagree.
2.1 Order of calculation
Pick the overall discount rule: combo scope, then category scope, then global. Ties are broken by priority, then id.
Pick the investor rule (only for active investors): custom % for that investor, then combo override, then category override, then plan default.
Apply the stacking mode from settings (see 2.2).
Apply guard rails: maximum total discount %, and never below cost price.
If the cap trims the total, the public overall discount is protected first and the investor part is reduced.
2.2 Stacking modes (admin setting)
Mode
Formula
Example (base 1000, overall 10%, investor 5%)
additive (default)
final = base - overall - (base x investor%)
1000 - 100 - 50 = 850
sequential
final = base - overall - ((base - overall) x investor%)
1000 - 100 - 45 = 855

Money handling
All calculations use integer paisa (minor units) internally and are converted back to BDT at the end. This avoids floating point errors like 0.1 + 0.2.
2.4 Order price snapshot
When an order is placed, the price breakdown (base, overall discount, investor discount, final price, discount id, plan id) is copied into order_items. Later changes to discounts or plans never change old orders.

4. API Reference
160 endpoints in 17 modules. Base URL is /api/v1.
4.1 Conventions
Topic
Rule
Success response
{ "success": true, "message": "...", "data": {...}, "meta": {...} }
Error response
{ "success": false, "message": "...", "code": "PRICE_BELOW_COST", "errors": [{ "field": "body.items.0.quantity", "message": "..." }] }
Pagination
Query page (default 1) and limit (default 12, max 50). meta returns page, limit, total, totalPages.
Auth
Access token in Authorization: Bearer <token>. Refresh token in an httpOnly cookie.
Status codes
200 OK, 201 Created, 400 Bad request, 401 Unauthenticated, 403 Forbidden, 404 Not found, 409 Conflict, 422 Validation failed, 500 Server error

Level
Meaning

Staff with that permission key, or admin.
Admin
Admin only.

6.5 TypeScript rules (no any)
Rule
How it is done
File names
<domain>.<layer>.ts in lower case, for example combo.service.ts. Middleware and util files keep the template names.
Exports
Controllers export plain handler functions. Services and repositories export one class instance (comboService, comboRepository).
Types
DB row types (ComboRow) are separate from API models (Combo). Public types never contain cost_price.
No any
Use unknown plus Zod parsing at the edges. strict, noImplicitAny, noUncheckedIndexedAccess are on. ESLint rule @typescript-eslint/no-explicit-any is set to error.
Return types
Every service and repository method has an explicit Promise<T> return type.
Money
API sends BDT numbers with two decimals. Pricing math runs in integer paisa inside pricing.util.ts.
IDs
BIGINT UNSIGNED in DB, number in TypeScript (safe range for this project).
Response shape
Success: { success, message, data, meta? }. Error: { success: false, message, code, errors? }.
Transactions
Multi-table writes (create combo, place order, approve investment) run inside withTransaction and pass trx to repositories.

6.7 Steps to add a new domain
Write the Knex migration and register the table in types/knex-tables.d.ts.
Create types/<domain>.types.ts (row type, API model, input types).
Create validations/<domain>.validation.ts (Zod schemas with satisfies RequestSchema).
Create repositories/<domain>.repository.ts extending BaseRepository.
Create services/<domain>.service.ts with business rules and AppError checks.
Create controllers/<domain>.controller.ts using catchAsync, validatedOf, sendResponse.
Create routes/<domain>.routes.ts and mount it in routes/index.ts.
Add unit tests for the service (mock repository) and one integration test for the route.

7.2 Route validation middleware
One Zod schema per route. validate() rejects bad input; validatedOf() gives the controller the exact same types.
 src/middlewares/validate.ts
import type { Request, RequestHandler } from 'express';
import { z, type ZodType } from 'zod';
import type { FieldError, ValidatedData } from '../types/common.types';
import { AppError } from '../utils/appError';
 
/** One schema object per route: any of body / query / params. */
export interface RequestSchema {
  body?: ZodType;
  query?: ZodType;
  params?: ZodType;
}
 
/** The parsed (coerced + defaulted) output types of a RequestSchema. */
export type ValidatedOf<S extends RequestSchema> = {
  body: S['body'] extends ZodType ? z.infer<S['body']> : undefined;
  query: S['query'] extends ZodType ? z.infer<S['query']> : undefined;
  params: S['params'] extends ZodType ? z.infer<S['params']> : undefined;
};
 
type Part = keyof RequestSchema;
const PARTS: readonly Part[] = ['body', 'query', 'params'];
 
/** Route-level validation. Rejects with 422 + field errors, or stores req.validated. */
export const validate =
  (schema: RequestSchema): RequestHandler =>
  (req, _res, next): void => {
    const data: ValidatedData = {};
    const errors: FieldError[] = [];
 
    for (const part of PARTS) {
      const partSchema = schema[part];
      if (!partSchema) continue;
 
      const result = partSchema.safeParse(req[part]);
      if (result.success) {
        data[part] = result.data;
      } else {
        for (const issue of result.error.issues) {
          errors.push({
            field: [part, ...issue.path.map(String)].join('.'),
            message: issue.message,
          });
        }
      }
    }
 
    if (errors.length > 0) {
      next(AppError.unprocessable('Validation failed', 'VALIDATION_ERROR', errors));
      return;
    }
 
    req.validated = data;
    next();
  };
 
/** Typed accessor used by controllers: types come from the SAME schema as the route. */
export const validatedOf = <S extends RequestSchema>(
  req: Request,
  _schema: S,
): ValidatedOf<S> => {
  if (!req.validated) {
    throw new AppError(
      'validate() middleware missing on this route',
      500,
      'VALIDATION_NOT_APPLIED',
    );
  }
  return req.validated as ValidatedOf<S>;
};
7.3 Global error handler
 src/middlewares/errorHandler.ts
import type { ErrorRequestHandler, RequestHandler } from 'express';
import { JsonWebTokenError, TokenExpiredError } from 'jsonwebtoken';
import { ZodError } from 'zod';
import { env } from '../config';
import type { FieldError } from '../types/common.types';
import { AppError } from '../utils/appError';
 
interface NormalizedError {
  statusCode: number;
  code: string;
  message: string;
  errors?: FieldError[];
}
 
interface ErrorBody {
  success: false;
  code: string;
  message: string;
  errors?: FieldError[];
  stack?: string;
}
 
interface MysqlError extends Error {
  code: string;
  errno: number;
}
 
const isMysqlError = (e: unknown): e is MysqlError =>
  e instanceof Error && 'code' in e && typeof e.code === 'string' && 'errno' in e;
 
const isBodyParseError = (e: unknown): boolean =>
  e instanceof SyntaxError && 'status' in e && e.status === 400;
 
const normalizeError = (err: unknown): NormalizedError => {
  if (err instanceof AppError) {
    return {
      statusCode: err.statusCode,
      code: err.code,
      message: err.message,
      errors: err.details,
    };
  }
  if (err instanceof ZodError) {
    const errors = err.issues.map((i) => ({
      field: i.path.map(String).join('.'),
      message: i.message,
    }));
    return {
      statusCode: 422,
      code: 'VALIDATION_ERROR',
      message: 'Validation failed',
      errors,
    };
  }
  if (err instanceof TokenExpiredError) {
    return { statusCode: 401, code: 'TOKEN_EXPIRED', message: 'Access token expired' };
  }
  if (err instanceof JsonWebTokenError) {
    return { statusCode: 401, code: 'INVALID_TOKEN', message: 'Invalid access token' };
  }
  if (isBodyParseError(err)) {
    return { statusCode: 400, code: 'INVALID_JSON', message: 'Malformed JSON body' };
  }
  if (isMysqlError(err)) {
    switch (err.errno) {
      case 1062: // ER_DUP_ENTRY
        return {
          statusCode: 409,
          code: 'DUPLICATE_ENTRY',
          message: 'Record already exists',
        };
      case 1451: // ER_ROW_IS_REFERENCED
        return { statusCode: 409, code: 'IN_USE', message: 'Record is used by other data' };
      case 1452: // ER_NO_REFERENCED_ROW
        return {
          statusCode: 400,
          code: 'INVALID_REFERENCE',
          message: 'Related record not found',
        };
      case 1213: // ER_LOCK_DEADLOCK
        return {
          statusCode: 503,
          code: 'RETRY_LATER',
          message: 'Please retry the request',
        };
      default:
        break;
    }
  }
  return { statusCode: 500, code: 'INTERNAL_ERROR', message: 'Something went wrong' };
};
 
export const notFoundHandler: RequestHandler = (req, _res, next): void => {
  next(
    AppError.notFound(
      `Route ${req.method} ${req.originalUrl} not found`,
      'ROUTE_NOT_FOUND',
    ),
  );
};
 
/** Global error handler: the ONLY place that writes error responses. */
export const errorHandler: ErrorRequestHandler = (err: unknown, req, res, _next): void => {
  const normalized = normalizeError(err);
 
  if (normalized.statusCode >= 500) {
    console.error(`[${req.method}] ${req.originalUrl}`, err); // swap with pino logger
  }
 
  const body: ErrorBody = {
    success: false,
    code: normalized.code,
    message: normalized.message,
    ...(normalized.errors ? { errors: normalized.errors } : {}),
    ...(env.NODE_ENV !== 'production' && err instanceof Error ? { stack: err.stack } : {}),
  };
  res.status(normalized.statusCode).json(body);
};

7.7 Service
Service-level checks: category exists, items exist and are active, base price is not below cost, unique slug.
 src/services/combo.service.ts
import { withTransaction } from '../config/db';
import { categoryRepository } from '../repositories/category.repository';
import { comboRepository } from '../repositories/combo.repository';
import { itemRepository } from '../repositories/item.repository';
import type { Viewer } from '../types/auth.types';
import type { Paginated } from '../types/common.types';
import type {
  AdminComboDetails,
  ComboImage,
  ComboImageRow,
  ComboItemDetail,
  ComboRow,
  PublicCombo,
  PublicComboDetails,
} from '../types/combo.types';
import { AppError } from '../utils/appError';
import { slugify } from '../utils/slug.util';
import type { CreateComboInput, ListCombosQuery } from '../validations/combo.validation';
import { pricingService } from './pricing.service';
 
const toPaisa = (v: number): number => Math.round(v * 100);
 
const toImages = (rows: ComboImageRow[]): ComboImage[] =>
  rows.map((r) => ({ id: r.id, url: r.url, isPrimary: r.is_primary === 1 }));
 
export class ComboService {
  /* ------------------------------ ADMIN ------------------------------ */
 
  async createCombo(input: CreateComboInput, actorId: number): Promise<AdminComboDetails> {
    // 1) Business validation (service-level error checks)
    const category = await categoryRepository.findActiveById(input.categoryId);
    if (!category)
      throw AppError.badRequest('Category not found or inactive', 'INVALID_CATEGORY');
 
    const itemIds = input.items.map((i) => i.itemId);
    const items = await itemRepository.findByIds(itemIds);
    const found = new Map(items.map((i) => [i.id, i]));
    const missing = itemIds.filter((id) => !found.has(id));
    if (missing.length > 0) {
      throw AppError.badRequest(`Items not found: ${missing.join(', ')}`, 'ITEM_NOT_FOUND');
    }
    const inactive = items.filter((i) => i.status !== 'active');
    if (inactive.length > 0) {
      throw AppError.unprocessable(
        `Inactive items cannot be used: ${inactive.map((i) => i.name).join(', ')}`,
        'ITEM_INACTIVE',
      );
    }
 
    // 2) Cost price = sum(item cost x qty)  (integer paisa -> no float drift)
    const costPaisa = input.items.reduce(
      (sum, line) => sum + toPaisa(found.get(line.itemId)?.cost_price ?? 0) * line.quantity,
      0,
    );
    const costPrice = Math.round(costPaisa) / 100;
    if (input.basePrice < costPrice) {
      throw AppError.unprocessable(
        `Base price (${input.basePrice}) is lower than cost (${costPrice})`,
        'PRICE_BELOW_COST',
      );
    }
 
    const slug = await this.uniqueSlug(input.name);
 
    // 3) Write everything atomically
    const comboId = await withTransaction(async (trx) => {
      const id = await comboRepository.insert(
        {
          name: input.name,
          slug,
          description: input.description ?? null,
          short_description: input.shortDescription ?? null,
          category_id: input.categoryId,
          base_price: input.basePrice,
          cost_price: costPrice,
          status: input.status,
          is_featured: input.isFeatured ? 1 : 0,
          sort_order: 0,
          created_by: actorId,
        },
        trx,
      );
      await comboRepository.insertItems(
        input.items.map((i) => ({ combo_id: id, item_id: i.itemId, quantity: i.quantity })),
        trx,
      );
      return id;
    });
 
    return this.getAdminDetails(comboId);
  }
 
  async getAdminDetails(id: number): Promise<AdminComboDetails> {
    const combo = await comboRepository.findById(id);
    if (!combo) throw AppError.notFound('Combo not found');
    const [items, images, availability] = await this.loadParts([id]);
    return {
      ...this.toCommon(combo),
      basePrice: combo.base_price,
      costPrice: combo.cost_price,
      availableQty: availability.get(id) ?? 0,
      items: items.get(id) ?? [],
      images: images.get(id) ?? [],
    };
  }
 
  /* ----------------------------- STOREFRONT ----------------------------- */
 
  async listPublic(
    query: ListCombosQuery,
    viewer: Viewer | null,
  ): Promise<Paginated<PublicCombo>> {
    const { rows, total } = await comboRepository.listActive(query);
    if (rows.length === 0) {
      return {
        items: [],
        meta: { page: query.page, limit: query.limit, total, totalPages: 0 },
      };
    }
 
    const ids = rows.map((r) => r.id);
    const [, images, availability] = await this.loadParts(ids);
    const prices = await pricingService.priceMany(
      rows.map((r) => ({
        comboId: r.id,
        categoryId: r.category_id,
        basePrice: r.base_price,
        costPrice: r.cost_price,
      })),
      viewer,
    );
 
    const items = rows.map((row): PublicCombo => {
      const pricing = prices.get(row.id);
      if (!pricing)
        throw new AppError(`No price for combo ${row.id}`, 500, 'PRICING_FAILED');
      const availableQty = availability.get(row.id) ?? 0;
      return {
        ...this.toCommon(row),
        pricing,
        primaryImage: images.get(row.id)?.[0]?.url ?? null,
        availableQty,
        inStock: availableQty > 0,
      };
    });
 
    return {
      items,
      meta: {
        page: query.page,
        limit: query.limit,
        total,
        totalPages: Math.ceil(total / query.limit),
      },
    };
  }
 
  async getPublicBySlug(slug: string, viewer: Viewer | null): Promise<PublicComboDetails> {
    const combo = await comboRepository.findActiveBySlug(slug);
    if (!combo) throw AppError.notFound('Combo not found', 'COMBO_NOT_FOUND');
 
    const [items, images, availability] = await this.loadParts([combo.id]);
    const prices = await pricingService.priceMany(
      [
        {
          comboId: combo.id,
          categoryId: combo.category_id,
          basePrice: combo.base_price,
          costPrice: combo.cost_price,
        },
      ],
      viewer,
    );
    const pricing = prices.get(combo.id);
    if (!pricing) throw new AppError('Pricing failed', 500, 'PRICING_FAILED');
 
    const imageList = images.get(combo.id) ?? [];
    const availableQty = availability.get(combo.id) ?? 0;
    return {
      ...this.toCommon(combo),
      pricing,
      primaryImage: imageList[0]?.url ?? null,
      availableQty,
      inStock: availableQty > 0,
      items: items.get(combo.id) ?? [],
      images: imageList,
    };
  }
 
  /* ------------------------------ helpers ------------------------------ */
 
  private toCommon(
    row: ComboRow,
  ): Omit<PublicCombo, 'pricing' | 'primaryImage' | 'availableQty' | 'inStock'> {
    return {
      id: row.id,
      name: row.name,
      slug: row.slug,
      description: row.description,
      shortDescription: row.short_description,
      categoryId: row.category_id,
      status: row.status,
      isFeatured: row.is_featured === 1,
    };
  }
 
  private async uniqueSlug(name: string): Promise<string> {
    const base = slugify(name) || 'combo';
    let slug = base;
    for (let n = 2; await comboRepository.slugExists(slug); n += 1) {
      slug = `${base}-${n}`;
    }
    return slug;
  }
 
  private async loadParts(
    comboIds: number[],
  ): Promise<
    [Map<number, ComboItemDetail[]>, Map<number, ComboImage[]>, Map<number, number>]
  > {
    const [itemRows, imageRows, availRows] = await Promise.all([
      comboRepository.findItems(comboIds),
      comboRepository.findImages(comboIds),
      comboRepository.findAvailability(comboIds),
    ]);
 
    const items = new Map<number, ComboItemDetail[]>();
    for (const r of itemRows) {
      const list = items.get(r.comboId) ?? [];
      list.push({ itemId: r.itemId, name: r.name, unit: r.unit, quantity: r.quantity });
      items.set(r.comboId, list);
    }
 
    const images = new Map<number, ComboImage[]>();
    for (const r of imageRows) {
      const list = images.get(r.combo_id) ?? [];
      list.push(...toImages([r]));
      images.set(r.combo_id, list);
    }
 
    const availability = new Map(
      availRows.map((a) => [a.comboId, Math.max(a.availableQty, 0)]),
    );
    return [items, images, availability];
  }
}
 
export const comboService = new ComboService();

import type { Knex } from 'knex';
import type {

export interface ComboItemJoined {

  quantity: number;

export interface ComboPage {
  rows: ComboRow[];
  total: number;

export class ComboRepository extends BaseRepository {
  constructor() {
    super();
  }
 
  findById(id: number, trx?: Knex.Transaction): Promise<ComboRow | undefined> {
    return this.conn(trx)('combos').where({ id }).whereNull('deleted_at').first();
  }
 
  findActiveBySlug(slug: string): Promise<ComboRow | undefined> {
    return this.conn()('combos')
      .where({ slug, status: 'active' })
      .whereNull('deleted_at')
      .first();
  }
 
  async slugExists(slug: string, trx?: Knex.Transaction): Promise<boolean> {
    const row = await this.conn(trx)('combos').where({ slug }).first('id');
    return row !== undefined;
  }
 
  async insert(data: ComboInsert, trx: Knex.Transaction): Promise<number> {
    const [id] = await trx('combos').insert(data);
    if (id === undefined) throw new Error('combos insert returned no id');
    return id;
  }
 
  async insertItems(rows: ComboItemInsert[], trx: Knex.Transaction): Promise<void> {
    await trx('combo_items').insert(rows);
  }
 
  /** Items of one or many combos, joined with the item master (name/unit). */
  findItems(comboIds: number[]): Promise<ComboItemJoined[]> {
    return this.conn()('combo_items as ci')
      .join('items as i', 'i.id', 'ci.item_id')
      .whereIn('ci.combo_id', comboIds)
      .select<ComboItemJoined[]>(
        'ci.combo_id as comboId',
        'ci.item_id as itemId',
        'i.name as name',
        'i.unit as unit',
        'ci.quantity as quantity',
      );
  }
 
  findImages(comboIds: number[]): Promise<ComboImageRow[]> {
    return this.conn()('combo_images')
      .whereIn('combo_id', comboIds)
      .orderBy([{ column: 'is_primary', order: 'desc' }, { column: 'sort_order' }]);
  }
 
  /** How many packs can be made from current stock = MIN(FLOOR(stock / qty per pack)). */
  findAvailability(comboIds: number[]): Promise<ComboAvailability[]> {
    return this.conn()('combo_items as ci')
      .join('items as i', 'i.id', 'ci.item_id')
      .whereIn('ci.combo_id', comboIds)
      .groupBy('ci.combo_id')
      .select<ComboAvailability[]>(
        'ci.combo_id as comboId',
        this.conn().raw(
          'CAST(MIN(FLOOR(i.stock_qty / ci.quantity)) AS SIGNED) AS availableQty',
        ),
      );
  }
 
  async listActive(query: ListCombosQuery): Promise<ComboPage> {
    const { page, limit, search, categoryId, minPrice, maxPrice, featured, sort } = query;
 
    const base = this.conn()('combos').where({ status: 'active' }).whereNull('deleted_at');
    if (search) base.andWhere('name', 'like', `%${search}%`);
    if (categoryId !== undefined) base.andWhere('category_id', categoryId);
    if (featured !== undefined) base.andWhere('is_featured', featured ? 1 : 0);
    if (minPrice !== undefined) base.andWhere('base_price', '>=', minPrice);
    if (maxPrice !== undefined) base.andWhere('base_price', '<=', maxPrice);
 
    const countRow = await base.clone().count<{ total: number }[]>({ total: 'id' }).first();
 
    const ordered = base.clone();
    if (sort === 'price_asc') ordered.orderBy('base_price', 'asc');
    else if (sort === 'price_desc') ordered.orderBy('base_price', 'desc');
    else ordered.orderBy('created_at', 'desc');
 
    const rows = await ordered.limit(limit).offset((page - 1) * limit);
    return { rows, total: Number(countRow?.total ?? 0) };
  }
}

7.9 Pricing engine
 src/utils/pricing.util.ts
import type {
  InvestorContext,
  InvestorDiscountRule,
  OverallDiscountRule,
  PriceBreakdown,
  PricingSettings,
  PricingTarget,
} from '../types/pricing.types';
 
/* All money math is done in integer paisa (minor units) to avoid float errors. */
const toMinor = (amount: number): number => Math.round(amount * 100);
const toMajor = (minor: number): number => minor / 100;
 
const SCOPE_RANK = { combo: 3, category: 2, global: 1 } as const;
 
/** Most specific scope wins (combo > category > global), then priority, then id. */
export const pickOverallDiscount = (
  rules: readonly OverallDiscountRule[],
  target: Pick<PricingTarget, 'comboId' | 'categoryId'>,
): OverallDiscountRule | null => {
  const matching = rules.filter(
    (r) =>
      r.scope === 'global' ||
      (r.scope === 'category' && r.categoryId === target.categoryId) ||
      (r.scope === 'combo' && r.comboId === target.comboId),
  );
  const [best] = [...matching].sort(
    (a, b) =>
      SCOPE_RANK[b.scope] - SCOPE_RANK[a.scope] || b.priority - a.priority || a.id - b.id,
  );
  return best ?? null;
};
 
/** custom % (admin, per investor) > combo override > category override > plan default. */
export const resolveInvestorRule = (
  investor: InvestorContext | null,
  target: Pick<PricingTarget, 'comboId' | 'categoryId'>,
): InvestorDiscountRule | null => {
  if (!investor) return null;
 
  const make = (percent: number): InvestorDiscountRule => ({
    planId: investor.planId,
    percent,
    maxDiscountAmount: investor.planMaxDiscountAmount,
  });
 
  if (investor.customDiscountPercent !== null) return make(investor.customDiscountPercent);
 
  const comboHit = investor.overrides.find(
    (o) => o.scope === 'combo' && o.comboId === target.comboId,
  );
  if (comboHit) return make(comboHit.discountPercent);
 
  const categoryHit = investor.overrides.find(
    (o) => o.scope === 'category' && o.categoryId === target.categoryId,
  );
  if (categoryHit) return make(categoryHit.discountPercent);
 
  return make(investor.planDiscountPercent);
};
 
const percentOf = (baseMinor: number, percent: number, capMinor: number | null): number => {
  const raw = Math.round((baseMinor * percent) / 100);
  return capMinor === null ? raw : Math.min(raw, capMinor);
};
 
const overallAmount = (baseMinor: number, rule: OverallDiscountRule): number => {
  const capMinor = rule.maxDiscountAmount === null ? null : toMinor(rule.maxDiscountAmount);
  const raw =
    rule.type === 'percentage'
      ? percentOf(baseMinor, rule.value, capMinor)
      : toMinor(rule.value);
  return Math.min(raw, baseMinor);
};
 
export interface PriceInput {
  basePrice: number;
  costPrice: number;
  overall: OverallDiscountRule | null;
  investor: InvestorDiscountRule | null;
  settings: PricingSettings;
}
 
/**
 * Pure function. No DB, no clock, no side effects -> trivial to unit test.
 *
 *   normal   : final = base - overall
 *   investor : additive   -> final = base - overall - (base * p%)
 *              sequential -> final = base - overall - ((base - overall) * p%)
 */
export const calculatePrice = (input: PriceInput): PriceBreakdown => {
  const { settings } = input;
  const base = toMinor(input.basePrice);
 
  let overall = input.overall ? overallAmount(base, input.overall) : 0;
  let investor = 0;
 
  if (input.investor) {
    const basis = settings.stackingMode === 'sequential' ? base - overall : base;
    const capMinor =
      input.investor.maxDiscountAmount === null
        ? null
        : toMinor(input.investor.maxDiscountAmount);
    investor = percentOf(basis, input.investor.percent, capMinor);
  }
 
  // Guard rails: total discount cap (%) and optional "never below cost".
  const capByPercent = Math.floor((base * settings.maxTotalDiscountPercent) / 100);
  const capByCost = settings.enforceMinMargin
    ? Math.max(base - toMinor(input.costPrice), 0)
    : base;
  const maxAllowed = Math.min(capByPercent, capByCost);
 
  let capApplied = false;
  if (overall + investor > maxAllowed) {
    capApplied = true;
    overall = Math.min(overall, maxAllowed); // public promotion is protected first
    investor = Math.min(investor, maxAllowed - overall); // investor part is trimmed
  }
 
  const total = overall + investor;
  return {
    basePrice: toMajor(base),
    overallDiscount: toMajor(overall),
    investorDiscount: toMajor(investor),
    totalDiscount: toMajor(total),
    finalPrice: toMajor(base - total),
    overallDiscountId: overall > 0 && input.overall ? input.overall.id : null,
    investorPlanId: investor > 0 && input.investor ? input.investor.planId : null,
    capApplied,
  };
};
